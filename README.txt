Ironveil Security - static website
===================================
Open index.html in a browser. No build step.

index.html     page markup
css/style.css  all styles
js/main.js     3D hero scene, tilt cards, defence stack, live feed, password check

Three.js r128 and Google Fonts load from the web, so an internet connection is needed for the 3D scene.
Brand name, figures, prices and the live feed are placeholder content.
